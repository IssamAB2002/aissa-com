# Main Prompt for Generating a Solvix Project Description

You are writing a polished project description for a Solvix portfolio page.
The description must be clear, attractive, and easy to read for visitors who are exploring your app project.

## Goal
Create a short but meaningful description for the Shippy Flutter app that explains:
- what the app does,
- why it exists,
- who it helps,
- and why it is useful for independent delivery agents.

## Requirements
- Write the description in Markdown only.
- Use simple, friendly, and professional language.
- Keep the tone appealing and easy to understand.
- Make the description suitable for a project showcase on Solvix.
- The intro should be short, engaging, and explain the app’s purpose in at most 3 lines.
- The features section should use bullet points.
- The conclusion should be short and satisfying, in at most 2 lines.
- Keep the overall description concise and not overly long.

## Structure
1. Intro
   - Introduce the app’s main purpose.
   - Highlight the problem it solves for delivery agents.
   - Make it interesting enough to encourage the reader to continue.

2. Features
   - List the main features of the app clearly.
   - Use simple bullet points.
   - Focus on the most important capabilities based on the app’s functionality.

3. Conclusion
   - Summarize the value of the app in a short closing paragraph.
   - End with a positive and confident note.

## Important Style Instructions
- Use headings such as #, ##, or other Markdown formatting when appropriate.
- Keep each feature easy to understand.
- Prefer a concise style rather than a long explanation.
- Emphasize that the app helps delivery agents manage their deliveries and finances more efficiently.
- If asked, include a short “Problem / Solution” angle in a very summarized form.

## Example to Follow
Use the example below as a reference for tone, structure, and style:

# Shippy

Shippy is a practical mobile app built for independent delivery agents to manage deliveries, clients, and daily finances in one place. It helps users stay organized, track earnings, control expenses, and make smarter business decisions without confusion.

## Features

- Track deliveries from pending to collected and settled
- Manage clients and delivery history
- Record package prices, delivery fees, and payments
- Handle client credit and hand-back amounts
- Log daily expenses like fuel, repairs, and food
- View earnings, expenses, and net profit clearly
- Group completed deliveries for easier settlement
- Support backup and restore for business data

## Why It Matters

Shippy gives solo delivery workers a simple way to run their business more professionally and efficiently. It saves time, reduces mistakes, and helps protect their income.

## Conclusion

Shippy is a smart and user-friendly tool for delivery agents who want better control over their work and money. It makes daily operations simpler, clearer, and more reliable.
