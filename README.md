# Aissa Com

## Description

Aissa Com is a multi-account e-commerce management mobile app built for teams.
Admins and employees each have their own accounts, with role-based access so employees have limited permissions.

It tracks your shop activity end-to-end: sales/income, orders, products, inventory, and operational tasks.
It also includes an employee rewards feature that calculates each employee's reward percentage based on contribution
(for example, replying to client messages) from the total benefits - summarized per day and per month.

## Core Modules

- Accounts & Roles: admin vs employee accounts with limited access for employees
- Orders: create, track, and manage customer orders and statuses
- Products: product catalog management (pricing, variants, availability)`
- Inventory: stock levels, adjustments, and inventory movements
- Income/Benefits: sales and income tracking with summaries
- Tasks: internal task tracking for daily operations
- Employee Rewards: daily and monthly reward percentage based on defined contribution metrics
